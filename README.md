<h3>📖 Project Overview</h3>
<p>
  The <b>Smart Land Rental Management System</b> is designed to streamline the process of renting land. It manages user accounts (Tenants, Owners), land listings, rental offers, agreements, and payment tracking.
</p>

<h3>🔍 Key Features</h3>
<ul>
  <li><b>Entity-Relationship Modeling:</b> Detailed ER and EER diagrams representing complex business logic.</li>
  <li><b>Relational Schema:</b> Conversion of ER models into normalized relational tables (Minimum 8 relations).</li>
  <li><b>PostgreSQL Implementation:</b> Database creation with Primary Keys, Foreign Keys, and Check constraints.</li>
  <li><b>Advanced SQL Queries:</b> Implementation of JOINs, Aggregate functions, and Sub-queries for reporting.</li>
</ul>
